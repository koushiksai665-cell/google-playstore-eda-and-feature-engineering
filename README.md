# Google Play Store EDA and Feature Engineering

Exploratory Data Analysis (EDA) and Feature Engineering on Google Play Store dataset.

## Contents
- `eda_google_playstore.ipynb` / `3.0-EDA+And+FE+Google+Playstore_code_only.ipynb`: Code-only Jupyter Notebook covering data loading, cleaning, feature engineering, and visualizations.
- `eda_google_playstore.py`: Python script formatted with interactive cells (`# %%`).

## Requirements
- `pandas`
- `numpy`
- `matplotlib`
- `seaborn`
